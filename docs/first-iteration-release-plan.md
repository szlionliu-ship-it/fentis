# 第一批发布计划（First Batch）

## 发布目标

- 将 Fentis 基础官网稳定上线，提供统一入口与健康探活能力。

## 变更内容

- 新增静态页面（品牌介绍、能力说明、发布准备区块）
- 新增 Nginx 配置（含 `/healthz`）
- 新增 Docker 与 Compose 启动配置
- 新增发布准备脚本

## 验收标准

- 首页 `GET /` 返回 200
- 健康检查 `GET /healthz` 返回 200 且 body 为 `ok`
- 容器可通过 `docker compose up -d` 启动

## 回滚方案

- 回滚到上一个稳定镜像 tag
- 如需紧急回滚，停止新容器并重新拉起旧版本容器

## 发布后观察（30 分钟）

- 5xx 错误率
- 首页响应时间
- 容器重启次数
