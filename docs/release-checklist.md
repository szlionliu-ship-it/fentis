# 发布检查清单（V1）

> 用于后续每次上线前逐项打勾，降低线上风险。

## 1. 需求与范围

- [ ] 本次需求有明确范围（页面、接口、数据影响）
- [ ] 验收标准已定义（可量化）
- [ ] 非目标范围已声明（避免发布时临时扩需求）

## 2. 代码与质量

- [ ] 核心功能已自测通过
- [ ] 关键路径已回归（登录、支付/提交、检索等）
- [ ] 已补充/更新必要测试（单测、集成测试或手工用例）
- [ ] 代码评审完成

## 3. 配置与安全

- [ ] 生产配置变更已复核（域名、证书、环境变量）
- [ ] 敏感信息未进入仓库（密钥、密码、令牌）
- [ ] 权限策略符合最小权限原则

## 4. 可观测性

- [ ] 日志可定位本次变更
- [ ] 监控面板准备就绪（QPS、错误率、延迟）
- [ ] 告警阈值已确认

## 5. 发布与回滚

- [ ] 发布步骤已文档化
- [ ] 回滚方案已验证（可在 10 分钟内执行）
- [ ] 发布窗口和负责人已确定
- [ ] 发布后 30 分钟观察项已定义
