# Fentis 网站迭代仓库

这个仓库用于继续完善并发布你现有的网站（`http://1.12.221.135/`）。

- 已确认线上地址可访问到网关，但返回 `403 Forbidden`。

## 建议迭代节奏（每轮 1~2 天）

1. **梳理现状**：收集现网功能、页面清单、接口清单、部署方式。
2. **确定目标**：定义本轮要改的 1~3 个可验收需求。
3. **实现与自测**：代码修改 + 本地验证 + 回归检查。
4. **发布准备**：变更说明、回滚方案、发布窗口。
5. **灰度/正式发布**：上线后监控错误率、性能和核心业务指标。

## 下一步（建议先做）

请先把以下任一内容补充到仓库：

- 线上项目源码（前端/后端）
- 或者最小可运行版本（包含启动命令）
- 或部署脚本与配置（例如 Nginx、Docker Compose、CI/CD）

有了代码后，我会按“需求 → 实现 → 测试 → 发布”节奏，逐步帮你完成每一轮。
